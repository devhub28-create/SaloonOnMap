# SLOT AI Style Studio — Privacy & Security Architecture

## 1. Privacy Principles

SLOT AI Style Studio handles facial photo processing strictly adhering to privacy-by-design principles:

1. **Explicit In-App User Consent**:
   - The user must review and check the explicit photo processing consent modal (`AiConsentDialog`) before any photo can be submitted for virtual styling.
   - The NestJS backend enforces `@Equals(true)` on `consentGiven`; any request without explicit consent fails immediately with `HTTP 400 Bad Request`.

2. **100% Local Processing — Zero Third-Party Leaks**:
   - The photo bytes **never leave the host infrastructure**.
   - No paid third-party cloud image generators (OpenAI, Midjourney, Replicate, AWS Bedrock, Google Cloud Vision) are invoked.
   - No external training data harvesting occurs.

3. **Strict Tenant & Cross-User Isolation**:
   - Every generation job (`AiStyleJob`) and saved look (`AiSavedLook`) is permanently bound to the authenticated user's `customer_id` (extracted securely from the validated JWT token).
   - Attempting to view (`GET /ai-style/jobs/:id`), retrieve, or delete (`DELETE /ai-style/looks/:id`) a look belonging to another customer throws `HTTP 403 Forbidden`.

4. **Biometric Data Safeguards**:
   - Facial landmark meshes (478 points) and hair segmentation masks generated by MediaPipe are calculated strictly **in ephemeral system RAM** to demarcate hair/beard boundaries.
   - No biometric signatures, facial embeddings, or face vectors are stored, cataloged, or linked to identity profiles.

5. **Complete User Deletion Rights (GDPR & CCPA Compliant)**:
   - When a user deletes a saved look via the app UI (`DELETE /api/v1/ai-style/looks/:id`), the database record is purged immediately.
   - When an account is terminated, all associated AI jobs and images are cascade-deleted (`ON DELETE CASCADE`).

## 2. Secure Data Flow

```
[Customer Mobile App]
       │
       │ (1) Authenticated POST /api/v1/ai-style/generate (Bearer JWT)
       ▼
[NestJS Application Server]
       │ (2) Validates JWT, verifies consentGiven == true
       │ (3) Persists original photo to local private filesystem
       │ (4) Records AiStyleJob(status='PROCESSING')
       │
       │ (5) Internal Server-to-Server loopback HTTP (127.0.0.1:8000)
       ▼
[Python AI Style Service]
       │ (6) MediaPipe inpainting execution (MPS)
       │ (7) Returns Base64 variations to NestJS
       ▼
[NestJS Application Server]
       │ (8) Writes styled PNGs to ./uploads/ai-styles/generated/
       │ (9) Updates AiStyleJob(status='COMPLETED')
       │
       │ (10) Returns variations payload to Customer
       ▼
[Customer Mobile App]
```
*(Direct client access from Flutter to Python port 8000 is blocked; all traffic is authenticated and filtered through NestJS).*
